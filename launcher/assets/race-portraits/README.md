These 64x64 Earthen (84) and Haranir (86) character portraits replace achievement
symbols in the ASR race picker. Both body types have their own portrait.

They are cropped from native ASR renders of the converted retail character
models, with their default skin and hair colors. They contain no UI border;
the native picker supplies the same frame as the other race portraits.
The source retail build was 12.1.5.70575. The race asset builder loads these
files directly and records their SHA-256 hashes in its portrait manifest.
