# ASR Simple Nameplates

Thin 72 x 6 health bars, without the large decorative border, level numbers or
skulls. Names appear on hover by default. Native health, reaction colours, raid
markers and click targeting are retained. Combat damage numbers are unchanged.

Install `ASR_Nameplates.zip` through **Options > AddOns > Manage AddOns > Install ZIP...**
and restart the game. Alternatively, copy this folder into the game's
`benilla-config/AddOns` folder. Enable it in Options > AddOns and enable enemy
nameplates in the game's nameplate settings. Use only one nameplate styling addon.

- `/asrplates names all` keeps small names visible.
- `/asrplates names hover` shows names only while hovering (default).
- `/asrplates names off` hides every plate's name.
- `/asrplates size 72 6` sets bar width and height (40–140, 3–14).
- `/asrplates reset` restores defaults.

Settings are saved between runs. Disable the addon and restart to restore native
plates; no native settings are changed. This addon is independent of ASR HUD.
