**ASR** is an RPG survivor-like game: pick a hero, fight off endless waves, level up and choose upgrades, and survive as long as you can, alone or in co-op with up to four players.

### Install

Download **[ASR-Setup.exe](https://github.com/calinadrian/asr/releases/download/game/ASR-Setup.exe)** below and run it. Choose where to install (no administrator rights needed), and it downloads the game (about 1.4 GB) and adds ASR to your Start menu. Uninstall it in Settings > Apps.

Windows may warn that the installer is from an unknown publisher; choose **More info > Run anyway**.

### Updates

ASR updates itself: when a new version is out, the game tells you when you start it, downloads it and restarts. Your characters and settings are kept.
