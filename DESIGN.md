# ASR — player experience

Players open the game directly. Co-op room browsing, hosting and joining belong inside the game window. Updates should also be offered inside the game; a separate launcher window is not the intended normal player flow.

A background connection helper can handle pinned TLS and server routing without showing another interface. Keep technical signing, server addresses and operator maintenance in the operator tools and documentation.

Preserve the original game’s UI, authorship and notices. The ASR name identifies this hosted co-op integration. The existing standalone maintenance interface is retained for compatibility while in-game update delivery is prepared.
